Calculation Notes

View Coverage, Assumptions and Risk Methodology

Broker EOD observations: 467; closed-session values: 321; full-session changes: 320; risk sample: 2025-07-03 → 2026-10-09.

  • Only the three user-selected brokerage / IRA accounts are included. The fixed-income account containing the two later capital contributions, employer retirement and equity awards are excluded entirely. No fixed amount is subtracted from earlier historical dates.
  • Historical data before the transfer to Schwab is unavailable due to a change of broker. Headline cumulative return equals the latest selected-account total divided by the user-defined initial capital, minus one. The annualized estimate uses this same capital basis and actual calendar time from the user-defined January 2025 start. This is a capital-reference comparison, not broker-certified time-weighted performance. All three accounts have simultaneous daily observations from July 2, 2025; no daily values or return path are invented for earlier dates, and the assumed January anchor is displayed separately.
  • Source: the user-visible Schwab Portfolio Performance value and net-contribution charts for each selected account. Rendered SVG coordinates are decoded against displayed beginning / ending values and contribution totals, rounded to cents, and checked for consistent dates and chart endpoints. Source evidence stays local.
  • Daily portfolio PnL is the change in summed selected-account values minus the change in their net contributions. Transfers between selected accounts cancel. As intraday flow times are unavailable, a daily Modified Dietz return uses previous value plus one-half of the net flow as the denominator. Cash flows are therefore excluded from profit; the intraday weighting is an explicit approximation. Monthly, YTD and risk-series returns geometrically link these daily estimates. They have a different basis from the headline initial-capital comparison and are not claimed to be a Schwab-certified three-account TWR.
  • This headline correction restores the user-defined initial-capital basis, replacing the observed-history return that was previously displayed at the top. The corrected three-account daily cash-flow and risk calculations remain in use; the earlier fixed-exclusion Total Value proxy remains superseded. Earlier reports and original source evidence are retained privately. Broker-provided single-account TWR is used as a reconciliation reference; the four-account TWR is outside the requested scope.
  • Daily risk uses XNYS sessions, including compounded weekend changes in the following trading-session interval. Weekend / holiday rows are not counted as separate zero-return sessions. Source values are broker end-of-day observations; NYSE close alignment is a calendar assumption. The report ends at the latest available broker date, not the collection date.
  • Volatility and Sharpe use 252 sessions per year. Sharpe uses excess session returns and FRED DGS3MO, accrued over actual calendar intervals / 365 with a conservative two-federal-business-day publication lag. These downloads are not historical vintages. Sortino uses a 0% target.
  • VaR uses negative session returns as losses and an empirical inverse CDF. Historical ES averages fractional mass in the worst tail. Parametric VaR / ES include the sample mean under a normal model. Thin-tail estimates remain provisional.
  • Historical stress windows and statistical shocks describe the observed return series, not current-holdings revaluation. Holdings-based scenarios, factor exposures, Greeks and prospective VaR backtests require additional evidence.
  • S&P 500 is a price index excluding dividends, normalized at the same January reference start using the last available closing quote; the benchmark has earlier daily history while account observations start later.
  • Account values, reference capital, contribution amounts, identifiers, holdings and transactions remain private. Public output contains percentage returns and dimensionless risk statistics only.
