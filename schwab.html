Calculation Notes

View Coverage, Assumptions and Risk Methodology

Historical table observations: 470; closed-session values: 323; full-session changes: 322; risk sample: 2025-07-01 → 2026-10-09.

  • Headline cumulative change uses adjusted account value relative to the user-defined starting capital. The annualized estimate applies geometric annualization over actual calendar days from the reference start to the latest snapshot.
  • The reference start is 2025-01-01. Actual Schwab history begins on 2025-06-30. The isolated starting point is a user assumption, not a retrieved account valuation. The missing interval is not interpolated or included as a daily return.
  • The same user-specified fixed exclusions are subtracted on every date. They are assumptions, not independently valued excluded-account histories. The resulting series is a user-defined adjusted Total Value proxy, not a verified sum of the originally selected accounts or official Schwab time-weighted performance.
  • The user confirms no other deposits, withdrawals or transfers. Cash flows are not independently reconciled. Values are date-only historical table observations aligned to XNYS session closes by assumption. The latest table row remains a snapshot and is excluded from full-session risk estimates.
  • Weekends and NYSE holidays are excluded from daily risk sampling; repeated non-session values are not counted as zero-return sessions. The first historical value anchors the daily series and is not a return from January. Missing sessions cause processing to stop.
  • Daily changes equal adjacent adjusted historical values divided by the prior value, minus one. Fixed exclusions can amplify percentage changes and risk estimates; unusually large changes are retained without winsorization.
  • Volatility and Sharpe use 252 sessions per year. Sharpe uses daily excess changes and the US 3-month Treasury yield from FRED DGS3MO, accrued over each actual calendar interval / 365. Rates are selected using a conservative two-federal-business-day publication lag; downloads are not historical vintages. The risk-free annual yield range is 3.62% to 4.42%. Sortino uses a 0% target.
  • VaR uses negative daily changes as losses and an empirical inverse CDF. Historical ES averages exact fractional mass in the worst tail. Parametric VaR / ES include the sample mean under a normal model. Loss quantiles are not floored at zero. Thin-tail estimates remain provisional; scenario outcomes are not probabilities.
  • Historical stress windows report observed compounded changes. Statistical shocks are mean minus a multiple of daily standard deviation, not current-holdings revaluation. Holdings-based scenarios, factor exposures, Greeks and prospective VaR backtests require additional evidence and are unavailable.
  • S&P 500 is a price index excluding dividends. BTC uses the latest completed Coinbase BTC/USD hourly spot candle at or before each valuation, excluding trading fees and holding costs. Benchmarks start at the last quote before the reference start. Their January–June performance is available even though account observations are unavailable.
  • Amount values, capital, fixed exclusions, account identities, holdings, transactions and source screenshots stay private. All published series contain percentages only. Calendar years and boundary months have explicit coverage labels; the current month includes the latest snapshot.
