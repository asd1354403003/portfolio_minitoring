## Binance

The strategy uses risk-adjusted cross-sectional momentum to select long and short positions in Binance USDT-M futures, with leverage and portfolio risk controls.

The report covers actual account PnL, cumulative and annualized returns, BTC and S&P 500 comparisons, monthly returns, drawdown, volatility, Sharpe, VaR, Expected Shortfall, scenario analysis and executed trades. Calculation methods and data timestamps are included in the report.

## Charles Schwab

The report shows percentage changes on a user-defined adjusted account-value basis, including cumulative and annualized reference changes, annual and monthly changes, BTC and S&P 500 comparisons, Sharpe, volatility, drawdowns, VaR, Expected Shortfall, and historical / statistical stress scenarios. The reference start is January 2025; observed account history begins June 30, 2025. Missing early history is not fabricated. Account amounts, capital, exclusions, identifiers, holdings and transactions remain private; calculation assumptions and data timestamps are disclosed in the report.

## Updates and repository contents

Reports are updated on request. New results replace `binance.html` and `schwab.html`; the report links stay the same.

Only these two HTML reports and this README are published here. Monitoring code, credentials, raw account records, CSV exports and historical archives remain local.
