View Return and Risk Methodology
  • Net PnL = closing equity − opening equity − external net flows. Modified Dietz adjusts for actual cash-flow timing; investment returns require verified flow coverage.
  • Historical VaR uses the empirical inverse CDF of losses; ES uses a fractional-sample weighted mean of the worst tail. Parametric VaR / ES assume normal returns. Negative loss quantiles are retained rather than floored at zero.
  • Statistical risk metrics require at least 30 valid daily returns. A thin 99% tail is provisional; a fixed observation count does not guarantee reliability.
  • Annualization uses 365 days for Binance and 252 sessions for Schwab. Sharpe requires a sourced risk-free rate; Sortino uses a 0% minimum target return by default.
  • Daily returns do not bridge missing sessions; drawdown uses the latest valid continuous interval. VaR backtests require forecasts retained before subsequent actual outcomes.
  • Schwab amounts, capital, account suffixes and holdings are excluded. Account Value change proxies are not cash-flow-adjusted investment returns.
